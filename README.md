# Credit Card Fraud Detection using Machine Learning

## Project Overview

This project builds a machine learning system to detect fraudulent credit card transactions.  
The main goal is to classify each transaction as either:

- **Not Fraud** → `0`
- **Fraud** → `1`

The project follows a complete fraud detection workflow including exploratory data analysis, preprocessing, feature engineering, model training, imbalance handling, threshold tuning, model evaluation, and final interpretation.
